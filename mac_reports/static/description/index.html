E3k Mac Reports

Résumé

Ce module personnalise les rapports imprimables de MAC Métal : commandes de vente, factures, bons de livraison, transferts et bons de commande fournisseurs. Il adapte la mise en page et le contenu de chaque document aux besoins spécifiques de l'entreprise, notamment l'affichage des conditions de livraison, du représentant aux ventes internes et d'un code QR de référence client sur les bons de livraison.

Module(s) requis

Rapports e3k par défaut (e3k_default_reports), Comptabilité (account), Livraison stock (stock_delivery), e3k MacMetal (e3k_macmetal)

Étapes de mise en place / configuration du module

  1. Dans Paramètres → Ventes, activer l'option « Conditions générales par défaut » et saisir les conditions à afficher sur les documents.
  2. Les rapports personnalisés remplacent automatiquement les rapports standard d'Odoo à l'installation.

Fonctionnement du module

  1. Le rapport de commande de vente affiche le représentant aux ventes internes, une note de livraison et les conditions générales configurées dans les paramètres.
  2. Le rapport de facture affiche les conditions de paiement et les termes et conditions, en masquant les informations de communication de paiement redondantes.
  3. Le bon de livraison affiche le numéro de commande client en titre, et génère automatiquement un code QR à partir de la référence client pour faciliter la réception.
  4. La mise en page des totaux de taxes sur les commandes et factures est ajustée selon les besoins visuels de MAC Métal.
  5. Le rapport de transfert inclut les informations de pesage, de transporteur et de numéro de suivi.
  6. Le bon de commande fournisseur est personnalisé avec la mise en page e3k.

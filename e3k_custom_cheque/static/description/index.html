CUSTOM CHECK

Résumé (1-2 phrases sur l’utilité / «features» du module)

Ce module permet de configurer le positionnement et la taille de la police de toutes les informations qui s'impriment sur un chèque, incluant les talons ("stubs"). Une fois configuré, les informations peuvent être imprimées sur un gabarit vierge de chèque préimprimé.

Module(s) requis

Comptabilité

e3k_advance_payment

Étapes de mise en place / configuration du module

  1. Dans CONFIGURATION / TECHNIQUE / RAPPORT, désactiver la fonction ''Recharger depuis la pièce jointe pour les trois (3) rapports ''Print check''

  2. Dans CONFIGURATION / PARAMÈTRES / COMPTABILITÉ, sélectionner l'emplacement du chèque sur la page (haut, milieu, bas) et activer l'option "Stub sur plusieurs pages"

  3. Dans COMPTABILITÉ / FOURNISSEURS / PAIEMENT, créer et confirmer un paiement par chèque à un fournisseur qui contient plusieurs factures à payer.

    Cliquer sur IMPRIMER pour voir l'état du chèque de départ.

  4. Il est important d'avoir en main un gabarit de chèque et non une copie scannée d'un chèque car il pourrait y avoir des différences vs la copie originale dus au scan et qui vont rendre les configurations inadéquates à l'impression du chèque (les informations seront décalées).

    Exemple d'un gabarit de chèque avec le chèque au milieu et les tableaux en haut et en bas.

Astuces possibles / autres informations importantes

Il est possible de décocher l'option d'imprimer le Stub sur plusieurs chèques pour ne pas "gaspiller" de chèques inutilement.

Il faudra alors imprimer le reçu de paiement en plus pour joindre le détail complet.

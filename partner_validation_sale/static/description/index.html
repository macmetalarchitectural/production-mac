Partner Validation Sale

Résumé

Ce module ajoute un processus d'approbation des clients avant de pouvoir confirmer une commande de vente ou valider une livraison. Un client passe par trois états successifs : Nouveau, Confirmé et Approuvé. Seuls les clients approuvés peuvent faire l'objet d'une commande confirmée ou d'un transfert sortant, renforçant ainsi le contrôle sur les nouveaux clients.

Module(s) requis

Validation partenaires (partner_validation), Ventes et inventaire (sale_stock)

Étapes de mise en place / configuration du module

  1. Assigner le groupe « Sales Partner Validation » aux utilisateurs autorisés à approuver les clients.
  2. Dans Contacts → Configuration → Champs restreints, définir les champs qui ne peuvent pas être modifiés sur un client approuvé (option « Appliquer sur les ventes »).
  3. Les nouveaux clients créés auront automatiquement le statut « Nouveau » jusqu'à confirmation et approbation.

Fonctionnement du module

  1. Chaque fiche client affiche son statut de validation (Nouveau, Confirmé ou Approuvé) dans la section Ventes.
  2. Un bouton « Confirmer » permet à tout utilisateur d'indiquer qu'un client est prêt pour approbation.
  3. Un bouton « Approuver » (réservé aux utilisateurs du groupe Sales Partner Validation) accorde au client le statut final permettant les transactions.
  4. Un bouton « Rejeter » remet le client à l'état Nouveau si nécessaire.
  5. La confirmation d'une commande de vente est bloquée si le client n'est pas encore approuvé, avec un message d'erreur explicite.
  6. La validation d'une livraison sortante vers un client non approuvé est également bloquée.
  7. Les champs désignés comme restreints ne peuvent pas être modifiés sur un client approuvé sans les droits suffisants, protégeant ainsi l'intégrité des données validées.

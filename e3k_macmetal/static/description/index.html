e3k MACMÉTAL

Résumé

Ce module est la personnalisation principale de MAC Métal pour Odoo. Il enrichit les commandes de vente, les transferts de stock, les contacts et les tickets de support avec des champs et des comportements propres aux opérations de l'entreprise. Il gère notamment les routes de livraison, les indicateurs de suivi des commandes, les représentants aux ventes internes et la signature des commandes par le client via le portail.

Module(s) requis

Ventes et achats (sale_purchase), CRM (crm), Calendrier (calendar), Inventaire (stock), Assistance (helpdesk)

Étapes de mise en place / configuration du module

  1. Aller dans Paramètres → Configuration des routes pour créer les routes de livraison (Route1 à Route6) avec leur code respectif.
  2. Dans Paramètres → Ventes, configurer les conditions de livraison par défaut et le nombre de jours de tampon pour les livraisons.
  3. Assigner les représentants aux ventes internes sur les fiches des clients.

Fonctionnement du module

  1. Les commandes de vente affichent la route de livraison, le représentant aux ventes internes, la date de réception, la date de suivi et les indicateurs « En attente » et « Remplacement ».
  2. La description des lignes de commande est affichée séparément du produit pour faciliter la lecture.
  3. Les clients peuvent signer leur commande directement depuis le portail client ; la date de livraison souhaitée est enregistrée lors de la signature.
  4. Les transferts de stock indiquent si la livraison est un retrait (pickup), si elle est en attente, et calculent automatiquement la valeur des ventes associées.
  5. Les contacts sont enrichis avec les champs Division, Représentant aux ventes interne et Maison-mère.
  6. Les tickets de support peuvent être liés à un type de produit et indiquer les montants anciens et actuels pour les ajustements de prix.
  7. Les conditions de livraison par défaut configurées dans les paramètres sont utilisées automatiquement dans les documents de vente.

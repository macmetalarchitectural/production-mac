Rapports par défaut E3K ("E3K default report")

Résumé

Ce module modifie les rapports Bon d’achat, bon de vente, bon de livraison et la facture de la manière suivante:

  • Garder deux adresses seulement dans l’entête (livraison et facturation)
  • Garder le même espacement entre l’entête, les adresses et le nom de fichier
  • Ajouter les termes de paiements dans le tableau d’informations du bon de commande
  • Ajouter la date requise dans le tableau d’informations du bon de commande. 
  • Séparer la colonne de référence interne de la colonne de produit
  • Ajouter le symbole ‘N°’ a tous les noms des rapports
  • Enlever le timing des dates (HH:MM:SS)
  • Grandir l’image du logo de l'entreprise
  • Ajouter l'information quantité commandée et quantité livrées dans les colonne des factures en option dans la configuration.
  • Ajouter un champs condition par défaut qui s’applique que pour les bon de commande dans la configuration générale du module vente. Le champs terme et condition par défaut du module comptabilité. Ne s’applique que pour les factures maintenant.


Module(s) requis

Ventes, achats, inventaire, comptabilité

Étapes de mise en place / configuration du module

  1.  Sélectionner « Configuration », puis « Comptabilité ».  

Fonctionnement du module

  1. Dans la section « Factures clients » vous avez la possibilité d'ajouter la colonne numéro produit, après avoir activer l'option "" depuis la configuration 
  2. la même chose pour les 3 autres configurations:
  3.  Dans l'anglet "Autres informations" dans le formulaire de la facture, ajout de deux champs : Payment reference et  Invoice print report, ce dernier est un champ selection, si il est dans l'option summary, ça active un anglet "Invoice text", ou on peut remplir et son contenu s'affiche dans la facture (ce champ est aussi la fiche du client et sera importer dans la facture (c'est disponible aussi pour les Vente dans le so)
  4.  dans les achats, ajoute la colonne 'Référence fournisseur' dans la liste des produit 'vue formulaire' et dans le rapport imprimé
  5.  le module ajuste aussi l'affichage des adresses client et fournisseur dans les rapports imprimé: ( rapport vente et achat et facture)

e3k Custom Sale Order

Résumé

Ce module personnalise le comportement des bons de commande et des factures afin que l'adresse de livraison ne soit jamais remplie automatiquement lors de la sélection d'un client. L'utilisateur doit choisir manuellement l'adresse de livraison, évitant ainsi les erreurs d'expédition dues à une sélection automatique non désirée.

Module(s) requis

Ventes (sale)

Étapes de mise en place / configuration du module

Aucune configuration requise. Le module s'active automatiquement à l'installation.

Fonctionnement du module

  1. Lors de la création d'un bon de commande, l'adresse de livraison n'est pas préremplie automatiquement lorsqu'un client est sélectionné.
  2. Lors de la création d'une facture client, l'adresse de livraison n'est pas préremplie automatiquement non plus.
  3. L'utilisateur doit sélectionner manuellement l'adresse de livraison souhaitée dans chaque document.

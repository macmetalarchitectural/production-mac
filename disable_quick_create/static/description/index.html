Disable Quick Create

Résumé

Ce module permet de désactiver l'option de création rapide (« Quick Create ») et l'option « Créer et modifier » sur les champs de type lien (Many2One) dans toute l'interface Odoo. Un administrateur peut configurer, modèle par modèle, lesquels ne permettent pas la création à la volée, forçant ainsi les utilisateurs à passer par les formulaires complets.

Module(s) requis

Aucun module requis.

Étapes de mise en place / configuration du module

  1. Aller dans le menu Paramètres techniques → Structure de la base de données → Modèles.
  2. Sélectionner le modèle pour lequel vous souhaitez désactiver la création rapide.
  3. Activer l'option « Désactiver Créer et Modifier » dans le formulaire du modèle.
  4. Enregistrer. L'effet est immédiat pour tous les utilisateurs.

Fonctionnement du module

  1. L'option « Créer rapidement » n'apparaît plus dans la liste déroulante des champs de lien lorsqu'elle est désactivée sur le modèle cible.
  2. L'option « Créer et modifier » est également masquée, obligeant l'utilisateur à ouvrir un enregistrement existant ou à passer par le formulaire complet.
  3. La configuration se fait modèle par modèle depuis la liste des modèles techniques, sans nécessiter de redémarrage du serveur.
  4. Le paramètre est mis en cache côté navigateur pour des performances optimales sans appels répétitifs au serveur.
  5. Tous les types de champs Many2One (produits, contacts, etc.) sont couverts automatiquement par ce module.
